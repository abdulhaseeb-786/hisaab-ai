# HisaabAI backend

See the main [README](../README.md) for setup, demo data and disclosures.

- `python -m app.simulator.reset`: rebuild the demo store now.
- `python scripts/export_openapi.py`: write the API contract for the frontend.
- `python scripts/build_public_benchmark.py <online_retail_II.xlsx>`: build the public benchmark CSV.
- `python scripts/forecast_benchmark.py`: run the forecast benchmark and write `docs/forecast_benchmark.md`.
