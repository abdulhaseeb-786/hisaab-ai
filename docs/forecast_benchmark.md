# Forecast benchmark

Generated by `backend/scripts/forecast_benchmark.py`. Rolling origin, 8 windows of 14 days per product; models only see data before each window.
Lower is better. *Daily error* is WAPE. *14-day total error* is the error on the total units over each window, which is what a reorder decision depends on.

## Public data

Not built yet: run `build_public_benchmark.py` to create `uci_online_retail_daily_top30.csv`.

## Simulated demo store (30 busiest products)

| Method | Daily error (WAPE) | 14-day total error |
|---|---:|---:|
| Calendar-aware smoothing (ours) **(best)** | 53.7% | 21.1% |
| Last week, same day | 69.6% | 22.8% |
| 7-day average | 54.2% | 22.7% |

240 product-windows evaluated.

Simulated accuracy is not evidence of real-world accuracy. The simulator's demand follows weekday and calendar patterns that the model is designed to find.
